讀取 `data/watchlist.yaml`，為光通訊族群產生結構化每日監控報告。
所有輸出語言：**繁體中文**（代號、數字、技術術語保留英文）。

## 執行步驟

1. 解析 `data/watchlist.yaml`：讀取 `global_thesis`、`monitoring_rules.priority_signals`、`tickers` 清單。
2. 取得今日報告的基準市場數據（QQQ、SOXX 當日漲跌）。
3. 對每一檔代號（依 YAML 順序：AAOI → LITE → COHR → MRVL → NOK → AXTI），搜尋過去 48 小時的新聞、法說會摘要、分析師報告、設計導入公告。
4. 拉取最新收盤價、單日漲跌幅、成交量比率（vs 20 日均量）、RSI。
5. 依下方格式輸出報告，存檔至 `reports/daily/YYYYMMDD.md`（使用今日日期）。

## 每檔格式（六節，依序輸出）

```
### [TICKER] — [公司名稱]
**層位**：[layer 欄位，以 / 分隔]
**現價**：$X  |  **單日**：+X%  |  **量比**：Xx 均量  |  **RSI**：XX

#### 1. 最新動態（過去 48 小時）
[新聞、法說會重點、分析師評等異動、設計導入 / 設計汰換公告。
無實質動態時寫：「無重大動態。」不要填充。]

#### 2. 論點評估：強化 / 弱化 / 不變
[三選一標籤，後接 1–3 句說明。
對照 YAML 中該股的 bull_triggers / bear_triggers 判斷。
套用 Howard Marks 第二層思考：好消息 ≠ 買訊，若已反映則不計。]

#### 3. 產能訊號
[生產擴產、交期、底材供應、晶圓廠利用率、訂單積壓變化。
AAOI：Texas 廠進度 + ATM 稀釋速度；LITE：NC fab 時程；AXTI：InP 供給集中度。]

#### 4. 客戶集中度變化
[新客戶導入、舊客戶流失、營收結構移動、design-in / design-out 訊號。
若頂部客戶佔比有重大變動，加 ⚠️ 標示。]

#### 5. 毛利率與稀釋訊號
[毛利率趨勢、營業費用槓桿、流通股數變化、負債水位、庫藏股回購。
COHR 特別追蹤：淨負債削減速度。AAOI 特別追蹤：ATM 進度。]

#### 6. 下一個關鍵檢查點
[未來 2–4 週最重要的單一事件或數據：法說會日期、投資人日、研討會、產品發布、客戶資本支出更新。
若尚未公布，寫明預估時間窗。]
```

## 週報模式

若 `$ARGUMENTS` 含 `--weekly`，改輸出週報至 `reports/weekly/YYYY-WXX.md`：
- 彙整本週五份日報
- 加：各標的論點進展（vs 上週）
- 加：本週最高信心多頭、最高疑慮標的
- 加：CPO 論點整體是否應上調 / 下調 / 維持
- 加：`global_thesis` 四條假設各自本週驗證結果

## 執行規則

- 不偽造價格數據——使用 WebFetch（finance.yahoo.com、benzinga.com）或標注「資料不可用」。
- 無新聞時寫「無重大動態」，禁止填充。
- 論點標籤必須對應 YAML `bull_triggers` / `bear_triggers` 具體觸發，不接受籠統判斷。
- 已知風險若今日無新資訊，不重複列入「最新動態」。
- 保留既有報告中人工補充的分析段落（`preserve_existing_notes: true`）。
